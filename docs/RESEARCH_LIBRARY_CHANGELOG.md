# Research library changes (independent of IFFT v0.4.1)

## 1.1.0 — 2026-11-03

Extend the local-only utility from file organization to an academic research workflow.
Add textbook, reading-note, writing-reference/draft, project and bibliography folders.
Add immutable page-numbered PDF/TXT/MD SQLite indexes, literal full-text search with
current-source SHA256 verification, duplicate-source deduplication, and explicit
blank-page/parse-error reporting. Add source-linked reading/writing-analysis cards
and project evidence/experiment/manuscript templates. Extend the Chinese Windows
menu while retaining commands 1–6 and all existing source-preservation behavior.
PDF extraction is optional and pinned in tools/requirements-library.txt.

No automatic document interpretation, OCR, semantic search, remote connection,
upload or IFFT processing change. Existing user files and instructions remain intact.
See the versioned validation record and GitHub Actions for test results.

## 1.0.0 — 2026-11-03

Initial root-scoped access probe, classification preview and verified copying,
SHA256 catalogs, text lookup, optional single-page PDF reading and Windows launcher.
